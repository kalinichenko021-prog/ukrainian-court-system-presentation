# 🎬 СУДОВА СИСТЕМА УКРАЇНИ
## Кінематографічна Презентація

> **Епічна HTML5 презентація про судову систему України з ефектами Крістофера Нолана**

---

## 🚀 Як запустити?

### **Варіант 1: Прямо з GitHub (Найпростіший)** 🌐

1. Перейди на сторінку репозиторію: https://github.com/kalinichenko021-prog/ukrainian-court-system-presentation
2. Натисни файл **`index.html`**
3. Натисни кнопку **"Raw"** в браузері
4. **Готово!** Презентація відкриється у повноекранному режимі

Або відкрий напряму через GitHub Pages (якщо увімкнено):
```
https://kalinichenko021-prog.github.io/ukrainian-court-system-presentation/
```

### **Варіант 2: Локально на своєму комп'ютері** 💻

```bash
# Клонуй репозиторій
git clone https://github.com/kalinichenko021-prog/ukrainian-court-system-presentation.git

# Перейди в папку
cd ukrainian-court-system-presentation

# Відкрий файл index.html подвійним кліком
# Або через браузер: Ctrl+O → вибрати index.html
```

### **Варіант 3: Через локальний сервер** 🖥️

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (встанови http-server)
npm install -g http-server
http-server

# Потім відкрий браузер: http://localhost:8000
```

## 🎨 КІНО-ЕФЕКТИ

Ось що заробило в цій презентації:

### ✨ **Основні ефекти:**

1. **Кен Бернс Зум** 📹
   - Камера вільно наближається/віддаляється
   - 8-12 секунд на кожному слайді
   - Стиль Крістофера Нолана
   - Тривимірна глибина

2. **Діафрагма (Aperture)** 📷
   - На обкладинці: діафрагма відкривається (чорні смуги)
   - На фіналі: діафрагма закривається
   - Класичний кіно-ефект

3. **Зерно Плівки (Film Grain)** 🎞️
   - Мікроанімація на кожному слайді
   - Аутентичний вид кіно 35mm
   - Пульсує з чергуванням

4. **Світлові Промені** ☀️
   - Неонові промені світла
   - Рухаються по екрану
   - Синій і зелений неон

5. **Пульсуючі Кільця** 💫
   - На ключових слайдах
   - Розширяються від центру
   - Символ важливості

6. **Монтажний Спалах** ⚡
   - На фіналі білий спалах
   - Має на увазі «вирізку» сцени
   - Профессійний кіно-стиль

7. **Каскадна Анімація Текстів** 📝
   - Титри проявляються знизу вгору
   - Текст розкривається зліва направо
   - Лінії зростають з центру
   - Затримки 0.1-0.2 сек між елементами

8. **Плавні Переходи** 🌊
   - Слайди розчиняються (fade) 0.8 сек
   - Прогрес-бар заповнюється
   - Лічильник оновлюється

9. **Неонові Кольори** 🟢🔵
   - Яскраво-зелений (#00ff88)
   - Синій неон (#0066ff)
   - Рожево-пурпурний (#ff0088)
   - Світлові ефекти (glow, shadow)

10. **Микро-взаємодії** 🎯
    - Кнопки світяться при наведенні
    - Картки піднімаються при hover
    - Активні компоненти мають гловс
